🎁 카드 등록 없이 3분 만에 구글 무료 키 받는 순서

  1. 구글 크롬에서 Google AI Studio (aistudio.google.com/app/apikey) 에 접속합니다. (현재 쓰시는 구글 계정으로 로그인)
  2. 파란색 [Create API key] 버튼을 누릅니다.
  3. 생성된 AIza... 로 시작하는 키를 복사합니다. (무료 등급인 Free of charge로 표시되며 하루 최대 1,500회 요청까지 0원입니다.)
  4. 이 앱의 [1. API 연결 설정] 탭에 붙여넣고 저장하면 끝납니다!
