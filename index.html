선생님 설정

1. Gemini API 키 (대화·칭찬·뜻 풀이)
2. 읽기 전용 정적 TTS 엔진 (100% 목소리·속도 고정)
문장·단어·다시읽기는 정적 TTS로 100% 일정하게 재생하고, 아이가 따라 말할 때의 칭찬과 질문 응답만 Gemini Live가 담당합니다.
기기 영어 음성 직접 지정 (선택)
Google Cloud TTS API 키 (비우면 위 Gemini 키 사용) Google Cloud 콘솔에서 Cloud Text-to-Speech API가 활성화된 키가 필요합니다. 오류 시 브라우저 고정 TTS로 자동 전환됩니다.
3. 동화책 선택 책 목록 주소 (구글 시트, 웹에 게시한 CSV 주소)
4. 선생님 목소리 성별 (100% 고정)
5. 말하기 속도 (정확한 배속 고정)
6. 마이크 방식
'계속 듣기'는 주변 작은 소음을 자동으로 걸러내며, '눌러서 켜기'는 한 번 눌러 말하고 다시 눌러 끄는 방식입니다.
